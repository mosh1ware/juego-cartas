# Juego de Cartas (Mil y Karioca) 

Un script en Bash para gestionar y disfrutar de tus juegos de cartas favoritos directamente desde la terminal.

## Requisitos
-Sistema operativo linux

## Instalación rápida
Puedes instalar el comando cts ejecutando:

```bash
git clone https://github.com/mosh1ware/juego-cartas.git
mv juego.cartas .juego-cartas
cd .juego-cartas
bash install.sh
